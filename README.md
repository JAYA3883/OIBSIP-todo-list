## 📌 Overview

This is a **fully functional, feature-rich To-Do List Application** built as Task 3 of my Web Development internship at **OASIS INFOBYTE**. The app helps users organize their daily tasks with powerful features like task categories, priority levels, due dates, analytics dashboard, calendar view, and more.

🔗 **Live Demo:** [View Live App](https://JAYA3883.github.io/todo-app/)

---

## ✨ Features

### Core Features
| Feature | Description |
|---------|-------------|
| ✅ Add Tasks | Create new tasks with title, category, priority & due date |
| ✅ Edit Tasks | Modify existing tasks |
| ✅ Delete Tasks | Remove unwanted tasks |
| ✅ Complete Tasks | Mark tasks as done with confetti celebration |

### Advanced Features
| Feature | Description |
|---------|-------------|
| 🏷️ Categories | Work, Personal, Shopping, Health |
| 🔥 Priorities | High, Medium, Low with color coding |
| 📅 Due Dates | Set deadline for each task |
| 🔍 Search | Find tasks by keyword |
| 🎯 Filters | Filter by category |
| 📊 Analytics | Visual charts for task completion |
| 📆 Calendar View | See tasks organized by date |
| 🎨 Dark/Light Mode | Toggle between themes |
| 💾 Auto-Save | Tasks save automatically in browser |
| 🎉 Celebrations | Confetti animation on task completion |
| 📈 Progress Ring | Visual progress indicator |
| 🔥 Streak Counter | Track daily completion streak |
